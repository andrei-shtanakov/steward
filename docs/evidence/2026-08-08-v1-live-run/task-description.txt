Break-glass runbook for steward SHA-bound waivers (gate-break-glass-path). Design and verify a reproducible operator runbook for the waiver/break-glass path of the steward governance gate: (1) allowed non-critical case — classify a change with `steward risk-classify` (ex-ante, explicitly declared scope), author a SHA-bound waiver file for a non-critical finding, validate it with `steward waivers-check`, and show the gate passing with the waiver recorded; (2) fail-closed rejections — a stale waiver (bound to a different SHA) and any waiver on a `critical` tier must be rejected with distinguishable messages and non-zero exit codes; (3) deliverables: docs/break-glass-runbook.md with exact commands, expected outputs and exit codes, plus fixtures/ with the waiver files for all three cases and a scripts/verify_break_glass.sh that replays the two negative cases and the positive case against a steward checkout pointed to by the STEWARD_DIR environment variable (invoke steward as `uv run --project "$STEWARD_DIR" steward ...`). Constraints: no modifications to steward sources; treat steward profiles/risk-model.yaml semantics as SSOT (a waiver on critical is forbidden by policy, this must be demonstrated not assumed); every claim in the runbook must be backed by a command the verify script actually runs.
